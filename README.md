One original rejected Olympic sport, in a single line: competitive elevator small talk. Athletes ride three floors in total silence, and the first to blurt out "So… weather, huh?" is disqualified on the spot. The event sounds like a real broadcast — a timed ride, a strict rule, an instant disqualification — while the sport itself is the awkward silence everyone already knows from real elevators. The line is 153 characters, inside the 1–200 character gate, and the program prints exactly that line, nothing else.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
